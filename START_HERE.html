06 / 核心业务

每条路线都包含办理步骤、预期结果和一种异常。跨岗位时请使用对应账号，并核对同一诊所；业务链接不会替你切换身份。切换身份后，旧确认页需要重新核对。

显示全部 6 条路线

01

患者、前台

预约、改期与取消

先核对安排，再确认决定，最后检查原新记录。

查看办理步骤与核对标准
  1. 患者

    选择服务和未来时间，核对诊所、医师及起止时间后明确预约。

    选择就诊时间 →
  2. 患者

    从本人预约进入改期，比较原新安排，再明确确认；另选一条合成预约演示取消。

    查看我的预约 →
  3. 前台

    使用同一诊所的前台账号核对日周排班和预约结果。

    核对日周排班 →
应看到的结果

一次确认只形成一个结果；改期保留原约历史并关联唯一新约；取消保留取消历史。

再核对一种异常

核对后时段被占：提交失败，原预约仍保留；重新查询后再决定。

个人核对结果 · 预约、改期与取消
02

患者、前台

候补与限时邀约

没有合适时间时，登记偏好并等待前台协调。

查看办理步骤与核对标准
  1. 患者

    登记可接受的诊所、服务和未来时间范围，查看候补状态。

    查看候补与邀约 →
  2. 前台

    在同店生成建议，核对资源后明确发布限时邀约。

    办理候补排班 →
  3. 患者

    核对邀约截止时间，选择新增预约或替换指定原约，预览后确认。

    核对并处理邀约 →
应看到的结果

登记和建议不形成预约；明确接受后，两端显示同一正式预约；替换时保留唯一后继。

再核对一种异常

拒绝邀约或退出候补：未确认的暂占按规则释放，已有正式预约继续保留。

个人核对结果 · 候补与限时邀约
03

前台

电话接待与成约

把咨询、联系责任和正式预约分别核对。

查看办理步骤与核对标准
  1. 前台

    核对患者身份和需求，新建合成接待单；不按相同手机号自动认定身份。

    打开电话接待 →
  2. 前台

    查可用资源，记录协商与后续责任；取得明确同意后办理正式预约。

    查询服务与资源 →
  3. 前台

    返回原接待单，核对沟通历史、成约状态及关联预约。

    核对接待结果 →
应看到的结果

咨询记录与预约各有历史；成功成约有唯一关联，联系未完成时仍有责任与期限。

再核对一种异常

患者拒绝或资源冲突：保留未成约原因及后续处理，不显示预约成功。

个人核对结果 · 电话接待与成约
04

前台、医生、患者

到诊、治疗与账单

由实际负责岗位记录服务，再核对已发布账单。

查看办理步骤与核对标准
  1. 前台

    找到本店预约，核对资源与到诊事实，再明确登记到诊。

    查看预约与到诊 →
  2. 医生

    使用负责该次就诊的医生账号，记录合成治疗事实，核对后完成接诊。

    进入本人接诊 →
  3. 患者

    在本人就诊详情查看已发布账单，比较治疗项目和金额。

    查看本人就诊与账单 →
应看到的结果

账单来自已完成接诊的发布版本；无治疗应保留原因和零金额，不伪造治疗项目。

再核对一种异常

未完成接诊或资料不全：显示待处理原因，不能把草稿当作已发布账单。

个人核对结果 · 到诊、治疗与账单
05

前台、财务、诊所主管

收款、退款与独立复核

分清账单收入、待审请求和已入账资金。

查看办理步骤与核对标准
  1. 前台

    对合成账单核对应收并提出资金记录请求；请求本身不是收款成功。

    核对应收与余额 →
  2. 财务

    由不同人员核对依据和金额后审核；另行核对退款或冲销。

    打开现金账与审核 →
  3. 诊所主管

    核对本店当日四类资金、未决事项与差异，再交由财务独立复核。

    核对日结与交接 →
应看到的结果

待审不计入已入账资金；原申请人不能自批；收款、退款、账单收入分别保留。

再核对一种异常

重复确认返回既有结果；金额或账单已变化时重新核对，不重复计款。

个人核对结果 · 收款、退款与独立复核
06

诊所主管、前台、财务

设备维护与预约协调

先看受影响安排，再交接维护与验收责任。

查看办理步骤与核对标准
  1. 诊所主管

    在本店设备台账提出合成维护工单，核对受影响预约。

    查看维护工单 →
  2. 前台

    逐条核对影响，与患者协商兼容资源或改期；未经确认不自动更改。

    查看资源影响 →
  3. 诊所主管

    完成维护后的事实核对与独立验收，再核对费用来源和财务状态。

    查看设备费用 →
应看到的结果

维修历史、安排协调和费用各自保留；送修不自动取消预约，也不自动记为付款。

再核对一种异常

资源不适配或患者拒绝：保留原约及待协调责任；缺失费用不能当作零费用。
