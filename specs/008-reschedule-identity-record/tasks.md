# 实施与验收

1. 在患者网页选时段和最终核对两处并列原约与新时间，保留候补、冲突和回执查询。
2. 为前台查询增加当前可见范围内的同名识别，跨页核对同一个患者编号并返回原清单。
3. 从医师工作清单直达这次检查或完整文书的草稿与当前确认版本。核对草稿和确认版同时存在、只有草稿、只有确认版及历史版。
4. 用独立 PostgreSQL 合成库、同名及跨店样本验证岗位范围，用浏览器验证上述三条路线和宽度、字号、键盘操作。在另一个数据库副本中实际确认一次改期，从旧记录打开新预约，再返回原约，核对只有一个后继和一份回执。用 `node scripts/check_patient_confirmation_browser.cjs` 检查普通预约和改期表单的提交地址。运行原有完整回归。
5. 交付原生患者改期工程、固定版本、可运行样本、校验文件和独立私有指南。小程序实际设备播报、大字和关闭调试由本批真机记录确认。
