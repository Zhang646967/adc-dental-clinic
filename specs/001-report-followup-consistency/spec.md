# Feature Specification — 报告复诊名称与本人查阅提示

**Feature** `001-report-followup-consistency`
**Baseline** `c7671267bc2c6e76d98ce04aea0de7ff19d0afb3`
**Created** 2026-11-15

## User Scenarios & Testing

### US1 · 患者辨认自己要约的服务（P1）

1. **Given** 排班内部名称与公开标题不同，**When** 患者从报告进入复诊，**Then** 网页和小程序的报告、服务选择及预约核对显示同一公开标题，并引用同一服务编号。
2. **Given** 门店暂停公开该服务，**When** 本人打开原报告，**Then** 可以查看报告、联系门店，既有复诊仍可回查。

### US2 · 代理理解本人查阅权限（P1）

1. **Given** 当前代理关系仍有效，**When** 代理打开报告相关链接，**Then** 双端拒绝查阅并说明本人限定，当前会话仍可办理获授权事项。
2. **Given** 登录、就诊人或授权已经变化，**When** 访问同一链接，**Then** 进入原有身份恢复路径，旧标题、正文、计数和按钮清空。
3. **Given** 签入的是另一患者本人，**When** 输入已知他人报告路径，**Then** 返回通用不可读结果，页面无前一身份资料。

### US3 · 看过报告后继续安排复诊（P1）

1. 本人读过报告后，仍能从双端「下一步」打开当前已发布的准确版本，继续查号或联系原门店。在诊、待确认邀约、已有预约和候补的优先级保持。
2. 建议期内无号时，从报告进入原查号页，沿现有路径联系门店或返回。预约取消且无接续预约时，按当前报告依据与日期重新计算下一步。
3. 已有有效预约可打开正式记录。已满足实际复诊目标、已撤回的报告和旧版本不产生新待办。站内提醒读态独立于复诊安排。

### US4 · 前台找出超建议期且未约的事项（P1）

在现有「复诊随访与责任」选择「超建议期未约」，可找到本门店已过医师建议最晚日期、尚无接续预约或实际完成依据的现行指示，沿用认领与跟进入口。「内部跟进逾期」仍按负责人跟进期限计算。同一条记录可同时符合两项。

### Edge Cases

- 建议窗口无号或已超范围时可联系门店。已改期复诊仍指向正式后继记录。
- 读态由本人明确标记。刷新和访问拒绝不改变读态。

## Requirements

- **FR-001** 当前公开的复诊服务使用目录公开名。服务编号、资格、窗口和历史预约快照继续取自各自的业务记录。
- **FR-002** 有效代理访问检查报告、提醒清单或标记已读时收到本人限定提示，拒绝响应不带报告、提醒标题、未读数或预约依据。
- **FR-003** 未登录、授权失效和跨患者访问维持各自原有结果。错误页保留查询编号和可用的返回入口。
- **FR-004** 当前报告和复诊能力继续通过原接口。方案、候补、结算及归档的权限合同保持。
- **FR-005** 双端共用当前报告复诊待办，适用于本人，独立于提醒读态。按发布日期及决策编号依序取首条可办理事项，已有预约和候补优先。下一步只引用报告准确版本，日期和门店规则沿用现有报告路径。
- **FR-006** 前台「超建议期未约」独立计算，使用北京时间与已有预约接续链及完成依据，只在当前门店现行指示中筛选。此筛选及患者下一步均只读。

### Key Entities

公开服务资料、预约服务、复诊指示、保留的预约快照、患者本人及代理授权。

## Success Criteria

- **SC-001** 网页报告、网页核对、小程序报告和小程序核对 4 处公开服务名称一致。
- **SC-002** 两类有效代理被明确拒绝并可返回，授权仍有效，未登录、撤权与他人访问按各自结果处理。
- **SC-003** 工具验收只读及预览，新增报告、读态、预约、实际处置及费用均为 0。
- **SC-004** 已读未约、无号、超窗、已有预约、改期后继、取消无后继与本人权限的双端结果可按同一合成记录对账。
- **SC-005** 前台可区分两类逾期、保留现有跟进入口，排除其他门店、有效预约和已完成目标，切换筛选不写业务状态。

## Assumptions

采用当前有效目录。服务退出目录后保留指示服务信息和门店联系路径。验证使用本机合成库。

思维导图　当前报告 → {本人下一步 → 查号／联系／回查，前台随访 → 建议期／内部期限} → 原记录与完成依据。

## 18547 · 椅旁复诊与患者到诊准备

复诊由明确关联的复诊指示识别。负责医师在本次接诊首页核对来源就诊、依据版本、牙位牙面、原就诊实际执行和本次过敏复核。每个来源独立列出。一位患者再次挂号本身不能证明两次就诊有同一治疗目标。

患者本人从本次预约查看原就诊和仍有效的已发布报告。原报告、检查版本、治疗步骤或适用服务变化时，保留预约，提示联系原门店。原预约已改期时由后继记录接续。预约代理只保留原预约范围。既有医疗授权范围和门店、医师隔离继续生效。浏览本功能只读。

## 正式配置下开通门店检查项目

门店在核验独立审核人、执行人和服务范围后，由技术管理员在该服务下开通指定项目。原有演练项目保留原类别。缺少有效非演练专业授权、同人兼任执行与审核、未开通或暂停的项目均不能发起新的报告办理。查看、写入和岗位工作清单按当前门店、项目、就诊归属及职责核对。

负责医师发布独立审核的准确版本后，患者本人能在站内收到一条对应提醒。打开清单不改变读态，按复诊指示确认时才创建复诊预约。负责医师与本店前台能够沿原就诊和指示核对同一个后继编号；前台无需读取报告正文。代理或其他患者不能查看他人报告。不自动发送外部消息、不产生收费。暂停项目保留已经成立的预约、版本与审计记录。
