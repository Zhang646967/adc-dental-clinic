# 实施顺序与验收

对应[离店后的复诊随访](spec.md)。以下均为拟执行任务。首批样本使用独立合成库，以执行日的北京时间生成相对日期。真实生成的就诊号、指示号和预约号在环境冻结时写入私有指南。

| 顺序 | 负责人及交付 | 进入下一步的条件 |
| --- | --- | --- |
| 1 | Codex 核对已有指示、联系事件、实际完成依据及改期链，在隔离库准备下表样本。先写“应由谁办、能办什么、患者会看到什么”，分别记录业务事实。 | 同一条指示在前台、医师和患者端均能对应到原就诊。列明授权范围、只读字段、允许的写操作和失败后的状态。 |
| 2 | Codex 实现服务端判断和前台网页。复用现有认领、接续、联系及完成命令，工作清单支持当前门店、本人待办和分页。用两个前台并发认领，并在一个旧页面打开期间从别处完成预约、改期或撤权。 | 每条指示只有一份责任记录，重复确认可回查原结果。旧页面提交时重新校验权限、当前预约与联系状态。已发生的联系保留历史。列表计数和对应筛选结果一致。另用同店 20 条和 200 条指示检查首页与分页，记录查询数和耗时，排查逐条读取全部历史才显示第一页的情况。 |
| 3 | Codex 完成负责医师工作台、患者网页及共用接口。按 R2 留存医师处理依据，区分“待医师处理”“已有依据可接续”。同一条指示在患者首页、原就诊及当前报告展示一致的状态和动作。 | 明确哪种记录能支持前台恢复协调。已结束的原就诊、失效授权、旧报告版本、原预约仍有效四种情况均通过服务端核对。冻结接口并留一套缺少新字段的兼容样本。 |
| 4 | WorkBuddy 在接口冻结后接小程序。沿用「主页」「就诊」「历史记录」和原就诊详情，核对角色切换、返回、旧接口及两处首页主行动。Codex 同时完成两端网页回归。 | Codex 先实测交接包能解压、校验、编译并访问该候选环境，再交用户转发。包内含候选提交、镜像标识、可运行工程、接口示例、验收任务和样本索引。包外私有指南备齐本人、预约代办、医疗代理、另一患者的账号、允许入口和证据目录。WorkBuddy 只读预置场景。 |
| 5 | Codex 集成同一候选版本，在前台网页、医师网页、患者网页和小程序上复查同一批指示。浏览器、微信开发者工具和手机各记其实测。 | 准确提交的完整 CI、双端回归和关闭调试的真机验收均通过后，才更新老师的既有试用入口。 |

## 开发记录

前台、医师、患者网页及共享接口的实现与对应回归见[候选验收](verification.md)。WorkBuddy 的[原生任务](workbuddy.md)与[接口约定](contracts/recall.md)使用同一组样本。原生回传和手机验收需在集成候选上完成。

## 隔离库样本

| 用例 | 预置或执行 | 必须观察到的结果 |
| --- | --- | --- |
| A · 到期边界（R1、R3） | 一条普通诊后指示今天到建议最晚日，另一条昨天到期且未约。另设一条建议期尚未来、前台内部期限已过的指示。 | 三种日期含义可区分。超窗指示不能沿旧窗口直接约。没有报告的普通指示也能从患者首页回到正确就诊。 |
| B · 认领与未接通（R1、R2） | 两名前台同时认领同一指示。成功者登记一次未接通，设明天的跟进时间。 | 留下一名负责人、一次联系事实。今日与未来待办随期限更新。患者端无已联系成功或已预约的提示。 |
| C · 本人暂缓（R1、R2、R3） | 登记本人暂不安排。由负责医师核对。再用同店其他医师和他店前台走权限负例。 | 待外联清单移除该项，负责医师可从本人待办定位。打开页面不产生处理回执。患者首页停止催约，原就诊仍可查看。实际恢复协调后保留原暂缓历史。 |
| D · 已约、改期与取消（R3、R4） | 一条报告关联指示已有正式预约并改期。另一条取消且无后继。准备一笔同人、同店、同服务但未关联的预约。 | 双端展示同一有效后继，旧时间归入历史。取消且无后继按当前指示重新判断。无关预约不能消掉待办。 |
| E · 多指示与依据变化（R3、R4） | 同一原就诊有两条不同指示，其中一条同时关联报告。更正或撤回报告，保留已有预约。 | 同一指示只计一次，两条指示各自有结果。入口遵循当前报告版本，仍可查回真实有效预约。同一人已有到诊或待答复邀约时，首页优先展示现有办理项。 |
| F · 完成与权限（R2、R4） | 分别准备仅到诊、部分执行、已有合格完成依据、医师已撤回四种事实。切换本人及两种代理，再从另一患者账号进入已知原就诊。 | 仅有合格依据可明确结案，撤回单列。代理守住原办理范围，他人无法读取原就诊，页面清空上一身份的内容。查阅不新增预约、联系事件、报告已读或资金记录。 |

**验收时让人回答两件事。** 前台从工作台指出“今天该由谁跟进，哪一笔应留给医师”。患者在关闭调试的手机上指出“我约好了吗，何时到店，尚未约时该找谁”。使用页面上的日期、门店和服务给出任务，记录实际答案、用时和误入页面次数。把建议日期当预约、向已暂缓患者继续催约、串人串店，均须修复后重测。
