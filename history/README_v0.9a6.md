# ADC v0.9.0-alpha.6：出诊安排的受控变更与停用

**候选源码，父版alpha.5；R4.4报告保持冻结。Windows本地最后确认运行v0.7，Mac迁移暂停。**

## 这次新增的业务入口

主管工作台 → 当前诊所 → **出诊安排** → 查看安排与影响。

没有有效占用且未开始时，可调整未来时间或停用原安排。调整不是覆盖旧时间，而是停用原记录、创建同店同牙医的新记录。原预约、邀约、治疗与账单不跟着移动。

存在预约/接诊或有效候补邀约时先拒绝变更，提供本店预约与候补协调入口。完整业务交接、自动改排、通知和临床资格审核不属于本轮。

## 开始验证

完整包在新的独立目录解压，不复制旧.env，不覆盖现有实例。Windows安装并启动Docker Desktop，在新目录执行：

```cmd
VERIFY_ISOLATED_WINDOWS.cmd
```

不需要宿主机Python。只有本次真实日志逐步成功且清理成功才是验证结果；不要将随包的静态检查当作你本机数据库已经通过。

- `docs/DEVELOPMENT_v09a6.md`：本轮开发与Windows验收路径。
- `docs/SU29_SU30_AVAILABILITY.md`：规约、规则、责任及边界。
- `docs/TEST_REPORT.md`：实际检查与未执行项。
- `scripts/check_availability_browser.py`：源模板与合成数据静态检查，不是真实E2E。

原Mac入口与迁移工具只是保留，不要求本轮运行。升级前先备份并验证带数据副本；累计包的文件重组核对不是数据库升级证明。
