# 正文图逐张核对和原版对照

页码为 PDF 阅读器显示的实际页序。新版图目录中的每条记录可直接跳到正文。47 张都是正文中的模型图，第五章另有六张操作画面。

本次对照原 299 页版第 11–29 页的业务和需求、第 41–127 页的系统与数据设计及第 128 页以后的实施和结果。老师给的参考稿第 20–23 页用于确定现状到改进的顺序，第 27–31 页对照岗位、用例图和规约，第 40 页对照分析序列，第 66 页对照预期与实测表。报告内容以本系统和已经留存的核对结果为据。

## 逐张核对
