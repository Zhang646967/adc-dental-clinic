# WorkBuddy：C3.3A工作边界与下一次接续

C3.3A只新增员工侧病历归档、医务独立审核和追加补正，没有新增患者小程序页面或认证链路。

本批不安排重新导入、编译、微信重登、解绑、医疗决定或费用操作。已通过的C3.2B2/C和C3.2C1结果保留其原版本和范围，原生版本选择手势、设备矩阵及手机条件仍分别记录，不补填通过。

下一次接续为C3.3B患者受控复制。Codex完成后端、员工受理、独立审核、材料范围和独立合成案例，取得准确版本CI并冻结新患者工程后，才提交新的部署任务单。WorkBuddy届时只负责新工程导入、必要编译及本人申请、进度、获准领取和访问隔离的患者侧工具回归；不操作医师、前台、后端或数据库。

只有认证逻辑、配置、密钥注入、会话或网关链路变化，或出现认证异常时，才安排针对性微信补验。固定HTTPS、平台主体与体验资格、第二真实身份和实际手机仍按具备条件的记录单独验收。
