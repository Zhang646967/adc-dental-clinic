2026-10-29的私有输入已修正字段位置。一次真实微信官方`stable_token`调用成功，未记录返回令牌、密钥或用户身份；这只证明该次服务连接和应用凭据被接受，尚不能证明用户微信登录或教师体验。后续运行结果单独归档。
