# 小程序四入口本地回归

核对版本 → 正常点击 → 查询业务结果 → 记录实测范围。

## 导入与边界

- 导入本轮交接包的工程，按 VERSION.json 核对客户端、后端、镜像和 CI。以 CHECKSUMS.sha256 核对交接包，校验后编译一次。旧工程和已验收库留作历史基线。
- 只在本轮独立合成环境办理写入。使用私有指南中的账号，不从旧环境取凭据。后端、源码、排班造例和数据库核对由 Codex 负责。
- 用正常页面点击、输入和返回操作。记录工具及基础库版本、页数、宽度、操作路径、查询编号和截图。证据留本机，公开材料仅保留汇总。

## 本轮场景

| 路径 | 预期 |
|---|---|
| 主页 → 找门店／找医师 → 预约就诊 | 首屏主操作清楚。拒绝定位后可选择城市，门店卡片可看营业和近期出诊，返回保留筛选。 |
| 门店或医师 → 选服务 → 原账号登录 → 选时段 | 门店、服务、医师和已选日期可恢复。覆盖不提供服务、暂无出诊、当天无可用时段三种结果，核对替代路径。 |
| 选时段或核对页 → 切换就诊人 | 保留公共预约选择，清除旧的确认与就诊需求。重新查询新就诊人可用的安排；医疗代理不能靠切换取得代约权限。 |
| 确认 → 就诊 → 对应预约 | 完成预约、改期、取消和候补；重复操作不新增记录。让 Codex 配合准备过期或已占用时段，改期失败时核对原预约。断网时先查结果，记录请求发出与否，不自行制造第二笔。 |
| 就诊 → 历史就诊／结算与病历副本 | 待邀约和下一次就诊排在历史列表前。只读检查入口与返回。无对应合成数据时记录待造例，禁止复用旧验收库办理。 |
| 我的 → 就诊人／账号安全／办理记录 | 原账号可用。切换账号后旧信息消失。预约代办与医疗代理权限各归其范围，未经授权的临床与结算链接被拒绝。 |

390 宽下记录长文、键盘和底部操作。375／430、字体放大、原生选择手势、PDF 阅读及实际手机分别记结果。有工具限制时记待验收。认证只按本轮变更的显示和入口复测；真实微信换码沿用既有证据，发现异常再补验。

回传每项 PASS／FAIL／待条件、客户端和后端版本、截图路径及实际新增记录编号。保留旧记录，密码和密钥只用本机私有指南。发布到微信平台与手机体验另行安排。
