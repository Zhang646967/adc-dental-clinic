# 小程序第二轮结果查询与返回路径复测

按任务入口打开 → 核对当前与历史状态 → 查询结果 → 返回原入口 → 核对授权。

## 交接和数据边界

使用本轮包的 VERSION.json 和 CHECKSUMS.sha256。四套项目的患者代码一致，配置分别连接对应本机合成后端。按所测场景导入必要工程并记录工具版本、基础库、屏宽、页数和工程树摘要。每套都以普通点击操作。账号沿用对应阶段的本机私有指南。

本轮专项回归以只读查询和取消预览为主。需要新写入或文件领取时先回传所缺样本，由 Codex 另行准备。尤其保留旧申请、医疗决定、撤销授权、账单及资金记录。原小程序代码、认证和平台检查沿用各自证据；本轮复测聚焦界面和导航。

## 需要现场配合的专项

- **医疗授权撤销结果**使用新的合成案例。确认后重新读取状态，撤销成功与该账号还能查阅什么分别核对。旧有效授权不用于本项写入。
- **副本文件读取失败**需新安排领取案例。确认领取和文件传输是两步，文件打开失败时仍显示已确认结果及申请状态。确认回复丢失只可查询结果或重试同一份签名提交。
- 上述异常分支已有受控测试。官方工具、实际设备及 PDF 文件阅读各自填写 PASS／FAIL／待条件。真实断网、拒绝定位、375／430、字体、键盘及原生选择手势延续独立验收。

回传版本、路径、实际状态、返回目的地、查询编号、证据文件及任何新增业务编号。公开材料只保留汇总，私有账号、具体个案和原始截图留本机。
