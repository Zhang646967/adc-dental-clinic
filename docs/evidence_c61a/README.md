## 已发现及修复

新增路由最初遗漏工作区白名单，现按七角色明确配置。两个财务账号并发首次导入或重新核对最初可能撞唯一键，现按来源事务锁串行且仍保留数据库约束。明确重提保留原拒绝或停用决定，不伪造政策版本；历史分页、前次链接及非法目标类型均补充实际HTTP反例。

第一次完整回归在独立临时验证库发生真实OOM：768MiB限额内的tmpfs同时承担数据库和累积WAL，检查点进程被系统终止。该次运行失败保留，未记作通过；改用任务专用磁盘卷，保持同一内存限额，最终1,826项回归无OOM或OOM kill。此次隔离环境故障不证明历史原系统工作进程退出的原因，旧UNDETERMINED与UNKNOWN记录仍保留。

当前只保存政策和合成准备资料，不产生患者、治疗、账单或资金；费用分担、基金到账及退费继续开发。真实微信授权、医保定点联网、云端、专业审定、新容量和24小时运行另行验收；历史Windows数据恢复仍为UNRESOLVED。私有日志、账号、密钥及加密备份不上传。

思维导图：保留原件 → {来源缺失、独立审阅、版本接续} → {本店、单位、待遇} → 无新增资金事实 → 分项交付。
