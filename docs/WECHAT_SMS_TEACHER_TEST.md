# 微信、手机注册与教师异地试用

公开找店 → 患者快捷登录 → 本人建档核验 → 原预约业务；员工使用独立登录入口。

## 当前试用

[教师试用系统](https://pressed-exact-network-automobile.trycloudflare.com)已使用从空库生成的课程合成数据开通。未设置邮箱门槛；业务操作仍需岗位账号。私有岗位密码由项目所有者另行提供，公开仓库不保存凭据。

微信／短信接入代码属于本轮源代码候选，准确应用CI、更新后的公网注册与绑定检查完成后再记录交付。当前已开放地址首先运行前一已验收应用；本页后续执行记录区分这两项事实。

| 登录方式 | 操作与所需配置 | 当前边界 |
|---|---|---|
| 微信小程序 | 点击登录，原生wx.login取得code，服务端向微信换取应用内身份 | 尚无注册AppID，未进行微信平台或真机验收 |
| 网站扫码 | 微信开放平台网站应用；回调为本站`/portal/auth/wechat/callback/` | 需实际网站应用和已配置的回调域名 |
| 微信内网页 | 公众号网页授权，使用独立公众号应用配置 | 需相应公众号及网页授权配置 |
| 一键绑定手机 | 小程序原生getPhoneNumber按钮，服务端交换手机号code | 需先绑定当前微信小程序身份，并开通手机号能力 |
| 短信注册／登录 | 手机号码、发送验证码、明确确认；未注册号码建立患者账号 | 腾讯短信需应用、已审核签名／模板及私有密钥 |
| 教师验证码测试 | 合成号码、发送测试验证码、在本页读取并填写 | 显示“未发送短信”，仅0开头的十一位号码；不能核验真实手机号 |

临时地址通过Cloudflare HTTPS隧道访问独立实例。Mac、Docker和隧道需保持运行；隧道重启可能改变地址。商用固定域名和独立云服务器仍需实际部署条件。[Cloudflare临时隧道说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。

## 教师办理路线

1. 无需登录，浏览城市、附近门店、地址、电话及营业时间；合成门址和联络资料均明确标注。
2. 从“患者登录”打开手机号注册；当前测试模式使用例如`00000000110`的未用合成号码。勾选同意，发送验证码，读取本页测试码并确认注册。
3. 进入“我的账号”，申请新建本人档案。前台使用独立账号，在所选门店的“本人档案开通核验”核对后批准；患者明确进入已授权服务，再预约、改期或候补。
4. 已分配患者账号可直接登录，并从“我的账号”验证绑定新的合成号码。换号后旧手机号登录凭据解除，原患者及预约关系保留。
5. 员工从`/accounts/login/`进入。前台负责排班；主管负责资源；财务经办与独立复核使用不同账号。请以合成资料记录建议。

## 身份与业务规则

微信只接受服务端交换得到的OpenID，不接受客户端自报身份；不按UnionID、手机号或姓名自动合并账号、患者档案。既有账号可在自己的患者账号页明确绑定微信或手机。首次登录不产生员工岗位、正式患者、预约、治疗或账单。原本人核验、代约授权、诊所范围及统一预约资源规则继续负责业务权限。

验证码五分钟、一次性、分用途并绑定会话；错误尝试最多五次，同号码至少间隔60秒，滚动24小时最多五次，同来源每小时最多十次，全局默认每日200次。发送失败也占用频率额度，避免接口故障触发反复发送。数据库只存验证码HMAC摘要；运行日志不包含号码、验证码、OpenID、AppSecret或会话密钥。真实短信回复只表示服务商接受请求，手机收到和本人输入核验分别确认。

每个账号最多一个有效手机号登录凭据；账号联络记录与患者档案联络记录分别保留。换号明确解除旧登录绑定，追加历史，不把旧号码转移到别人的患者档案。微信绑定与短信绑定均不能接管其他已绑定账号。密码停用仍由原账号治理处理。

## 私有配置

以根目录[PATIENT_AUTH_ENV.example](../PATIENT_AUTH_ENV.example)为字段清单。AppSecret、短信密钥及岗位密码仅放私有服务端环境。小程序只保存自己的公开AppID及HTTPS后端地址。生产配置选择`tencent`短信服务；教师`demo`同时要求`ADC_RC_SYNTHETIC=1`和`ADC_TEACHER_TEST_MODE=1`，不作真实服务失败时的后备。

网站、公众号、小程序可以有不同AppID。当前不会依靠未验证的跨应用标识自动关联，用户通过原账号核验后明确绑定。微信回调需要准确公网域名；临时地址不能代替正式平台域名配置。

官方接口依据：[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)、[手机号授权](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)、[网站应用微信登录](https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html)、[腾讯短信2021-01-11接口](https://cloud.tencent.com/document/api/382/55981)、[TC3签名](https://cloud.tencent.com/document/api/382/52072)。真实平台验收须在实际账号条件下执行；模拟供应商测试不代表已开通微信或发送真实短信。

思维导图：患者入口 → {微信登录、短信核验、已有账号} → 明确绑定与账号历史 → 本人／代约权限 → 预约诊疗；教师测试 → {合成空库、独立岗位、HTTPS地址、反馈}。
