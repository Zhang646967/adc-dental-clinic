# 医保资料准备：本地试用

政策原件 → 两名财务核对 → 本店安排 → 逐项收费适配 → 前台待遇核对 → 原账单准备。

员工使用[独立员工入口](http://127.0.0.1:18000/accounts/login/)，进入[医保资料与模拟待遇](http://127.0.0.1:18000/insurance/)。网站访客找店和患者小程序仍先浏览门店，个人业务再登录；医保员工职能不放进患者小程序。

## 办理路线

1. 财务查阅湖南口腔目录的通知、原件、编码及缺失项。新来源先预览、再明确保存；由另一财务账号核对后启用。原件下载为实际Word二进制格式.doc。
2. 目录未通过或停用后，可从原记录“重新提交同一来源核对”；原政策版本及原决定保留，新的审阅次数另行复核。
3. 主管在当前诊所准备有起止日期的课程模拟安排，财务独立确认。同店已确认安排的日期不能重叠，公开营业或就诊城市不能替代医保安排。
4. 主管从原收费项目明确选择政策项目、单位数量换算和依据，财务独立核对。没有专业适配依据时保持未映射；缺少单位或支付规则继续待核对。该操作不改原价格、治疗数量和账单。
5. 前台从本店患者档案进入“核对模拟医保待遇”，分别填写合成参保地、类型、有效期、结果和SIM依据；先预览再确认。变更新增版本，最新待核实不会自动使用旧已核对结果。
6. 停用保留全部历史，阻止新用途；原记录、拒绝决定和后续审阅可相互查阅。总部只查看数量汇总，技术管理不代替业务复核。

## 当前课程配置

本地试用仅使用合成资料。湖南来源和长沙四家合成门店的课程安排按正常业务命令准备；独立财务试用账号及实际有效期见本机私有文件.course-private/c61a-20261025/课程医保试用账号.txt。该文件不上传仓库。原账号密码保持不变。

原患者待遇、历史治疗和资金未补造；没有明确适配依据的原收费项目保持未映射。此批可验证资料责任和审核流程，费用分担、唯一模拟结算、基金到账及退费属于后续C6.1B/C。

真实微信登录不能直接取得居民身份证信息；当前账号、手机和待遇只按已标识的本地模拟或人工流程办理。AppID及真实医保机构条件尚未提供，真实平台和医保联网未验收。
