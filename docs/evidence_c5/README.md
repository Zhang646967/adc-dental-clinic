# C5 批次、护理执行与费用验收

| 核对项 | 执行结果 |
|---|---|
| 浏览器流程 | 门店主管登记耗材，药师登记药品批次并发出，护理记录实际给药、耗用、无菌包使用与异常，药师按原批次退药隔离并召回，医师结算。 |
| 数量 | 到货药品 5，发出 4，实际给药 2，退回隔离 1，库存余额 1。耗材到货 6，耗用 2，余额 4。召回清单可按原发药追溯就诊。 |
| 金额与岗位隔离 | 混合账单保留一笔牙科治疗 ¥80.00 和净药费 ¥37.50。前台护理页拒绝，跨店护理只读负例拒绝。 |
| 定向回归 | 8 个 C5 PostgreSQL 场景和 85 个组合用例通过，覆盖库存及给退药并发、撤权、过期、召回、无菌包重复使用、患者账单与病历归档。 |
| 实际结构 | 93 份应用迁移，保留原 88 份。185 张 SQL 表、184 张 ORM 表、540 条外键及 172 项业务触发器。 |
| 独立加密恢复 | 同版本迁移建库后恢复并比较 185 张表、1,200 行，含 5 笔库存流水和 4 笔护理执行。 |
| 患者小程序 | 药费单列并保留旧客户端兼容。源码与页面处理逻辑验证、实际 Django 本人及越权接口均通过。同一客户端接入 C4.2 合成后端，在 390 px 微信开发者工具通过两版药费、当前余额、返回就诊与越权隔离复测。 [版本与范围](../evidence_c42/workbuddy-closure.json) |
