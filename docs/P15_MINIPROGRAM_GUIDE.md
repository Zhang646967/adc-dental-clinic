# P1.5 患者小程序使用

找店选医 → 选择服务与日期 → 登录并核对就诊人 → 确认预约 → 就诊、候补与本人结算。

小程序是患者主入口，网站使用相同患者权限和业务规则。工程有24个原生页面，四个固定入口为主页、预约、就诊、我的；员工使用独立网站工作台。

## 找店与选医

主页可匿名筛选城市、服务、区域和线上预约条件。主动使用定位后，先对完整二十店索引按距离排序，再分批显示。门店详情包含三张课程环境示意图、团队、实际服务、营业和到诊信息；医师详情区分专业方向与本店可预约服务。

二十店均提供初诊、洁牙与牙龈护理、牙痛评估与基础修复、复诊四类基础服务。正畸、缺牙修复与儿童服务按店配置。没有支持的特色服务时显示实际可办理的同城门店；无同城替代则明确说明。

## 预约与就诊人

先选门店或先选医师均可继续服务与日期。未选日期时使用相应医师与服务最近的已发布出诊日，查询不占位。登录后核对本人或已授权就诊人，明确确认才成约；已有预约造成冲突时可另选日期、医师或候补。

长沙星沙儿童试用须由前台已核验的监护人选择就诊人。一般预约委托不等于监护，代约也不包含临床、治疗方案决定或结算单读取。改期保留原约关联；取消和退出候补均需明确确认。

## 就诊与结算

“就诊”集中已有预约、候补、健康自述、治疗方案、转诊及本人记录。“我的”管理账号、档案申请与就诊人。已有发布账单的本人预约详情提供原生结算单，保留收费项目、版本金额和当前已记账收退款余额。历史金额与当前余额适用版本分开显示，未开单不解释为免费或已付款。

## 工程与验证

仓库的 `clients/wechat/` 是源工程；已生成的可见工程、ZIP、预览码和私有账号说明交付在用户试用目录。导入包含 `project.config.json` 的完整文件夹。源码默认游客AppID；实际试用工程保留用户注册AppID，密码及平台密钥放在工程外。

本地模拟器的127.0.0.1指向开发电脑；手机须连接已核验HTTPS后端。开发调试包与正式体验版分别评价，手机实机验收按用户安排后置。真实微信和短信仍待配套平台配置，不以指定账号登录或工具测试替代。
