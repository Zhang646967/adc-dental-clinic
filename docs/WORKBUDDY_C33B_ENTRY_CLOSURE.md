## 工程树摘要的复现约定

工程树摘要是公开的SHA-256拼接约定，不使用私有密钥或秘密算法：按相对路径排序，将每个文件的“路径、NUL字符、文件SHA-256、换行”以UTF-8拼接，再计算SHA-256。以下对交接包中的干净工程执行；开发工具后来生成的私有配置或缓存不属于已交付的90个文件。

```python
from pathlib import Path
import hashlib

root = Path('微信小程序-病历副本入口修复18382')
files = sorted(p for p in root.rglob('*') if p.is_file())
records = ''.join(
    p.relative_to(root).as_posix() + '\0'
    + hashlib.sha256(p.read_bytes()).hexdigest() + '\n'
    for p in files
)
print(hashlib.sha256(records.encode('utf-8')).hexdigest())
```

预期为`e9ac2f1ec2b66b660448ecd55ca6027b76d48a4675f42258d062559e899e2230`。本轮亦独立复算一致；WorkBuddy的92项校验及单文件比对本身已经提供独立核验，不因此要求重测。
