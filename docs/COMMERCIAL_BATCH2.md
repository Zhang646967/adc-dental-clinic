# 第二批整改与目标环境验收

患者关键路径 → 外部观测 → 异地恢复 → 手机及目标机验收。

第一批已关闭预约联系、门店资料、网页筛选和报告状态四项一致性问题。第二批按专家评审顺序处理真实运行，优先从患者实际操作观察服务。目标环境使用独立服务器、固定 HTTPS 与专用合成样本。独立运行的既有工具和证据见 [D2.3](D23_INDEPENDENT_OPERATIONS.md)。

| 优先级与问题 | 本批可执行标准 | 目标环境通过标准 |
|---|---|---|
| P0 患者链路可能在健康页正常时失效 | 独立 HTTPS 探测走公开找店、游客拒绝、本人登录、查号、读取本单、他单拒绝和退出。注入真实网关故障后定位失败步骤，两次连续失败产生告警事件，恢复后产生恢复事件。回执仅保留技术指标 | 独立观测点使用系统信任的固定域名。连续 24 小时每分钟一轮，计划采样齐全且起步迟延不超过 10 秒，至少 99.9% 轮次成功且耗时不超过 5 秒，结束时无未恢复告警。另以真实预约提交及回查验证写路径 |

外部探测属于读取型业务监测，只执行患者登录与退出的会话操作。独立合成环境用于确认、改期与取消的实际写入验证。目标容量沿用既有目标机测试合同及记录口径。[目标环境合同](COURSE_ONLINE.md#target-acceptance目标环境验收) · [基于用户体验的服务指标](https://sre.google/workbook/implementing-slos/)

本批证据按本机回归、WorkBuddy 工具及设备、目标服务器三个层次分别记录。

## 外部探测操作

在独立观测机准备仅所有者可读的 JSON 文件，使用专用合成患者账号和已核对的两笔预约。字段为 `scope`（固定为 `synthetic-patient`）、`host`（固定域名）、`username`、`password`、`clinic`、`service`、`own_visit` 和 `foreign_visit`。编号采用正整数。本人预约与所选门店一致，他单属于另一名合成患者。

```sh
python3 scripts/g4_patient_probe.py \
  --fixture /PRIVATE/patient-probe.json \
  --receipt /PRIVATE/first-probe.json
python3 scripts/g4_patient_probe.py \
  --fixture /PRIVATE/patient-probe.json \
  --receipt /PRIVATE/target-observation.json --observe
```

目标模式使用直连 HTTPS 和系统信任链。每轮建立独立会话，核对候选列表与可约状态的一致性。有排班但无组合或暂未排班属于有效业务结果。另行执行隔离写入场景核对预约提交和回查。

回执按轮原子写入私有目录。连续两轮失败或超时发出 `OPENED`，首轮恢复发出 `RECOVERED`。进程中断保留 `INCOMPLETE`；窗口内的失败记录随恢复保留。告警接收端监视进程、最后观测时间与事件送达。在目标机验收一次真实告警到达与恢复确认。接收方仅需失败步骤、状态码、耗时与请求编号。

通过判定同时检查实际 UTC 采样顺序、相邻间隔和相对起始计划的时间偏差。首末样本覆盖完整计划窗口，时钟与单调计时的偏差容许一秒。记录齐全但有断档、重复或逆序时，汇总为 `FAIL`。

在独立于探针进程的定时任务中每分钟执行以下检查。探针或其所在主机可能同时失联时，由另一个观测点读取经私有通道同步的最新回执。

```sh
python3 scripts/g4_probe_watch.py \
  --receipt /PRIVATE/target-observation.json \
  --state /PRIVATE/probe-heartbeat.json
```

巡检以最后一轮或启动时刻为准，超过两个采样间隔加十秒标为 `STALE`，缺失或不可读标为 `UNAVAILABLE`。业务探针发出 `PATIENT_JOURNEY`，独立检查发出 `PROBE_HEARTBEAT`。各自记录 `OPENED` 与 `RECOVERED`。探针正常结束时返回 `FINISHED` 并附窗口结果。换新观察窗口时给巡检指向新的回执，延用同一目标的心跳状态。把事件和巡检退出状态接到目标告警渠道，分别验证业务故障、探针失联和两者恢复。

本机短时演练使用 `--rehearsal --https-port 18477 --ca-file /PRIVATE/rehearsal-ca.pem`。此模式固定连本机 IPv4 回环。目标证据另核对真实域名、独立观测点、主机和证书续期、对象存储、真实手机与完整观察窗口。
