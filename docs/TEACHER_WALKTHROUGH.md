# 门诊岗位办理指南

从[门诊系统](https://lijiahao.duckdns.org/)进入。访客可直接查门店和诊疗服务；办理个人业务时选择「患者登录」或「员工登录」。持私有邀请者使用获准岗位，正式使用者以本人账号登录。

## 患者 · 确定下次到店时间

打开「我的预约」，记下就诊编号、门店和起止时间。选择「调整这次预约」，核对原约与拟选时间；预览期间原约继续有效。明确确认后，打开回执对应的预约，核对是否仍需到店。多次改期时，可以从中间记录分别打开前一笔和后一笔，按每笔记录自己的状态判断。若最后一笔已取消，下次安排以之后实际约成的记录为准。

## 前台 · 核对同名患者并登记到诊

在前台工作台选择负责门店，打开「患者档案」。输入姓名，按患者提供的**完整患者编号**核对。打开对应预约，把就诊编号、医师和时间与患者端逐项核对。本人实际抵达后才登记到诊；返回清单核查另一位同名患者的状态。接诊和医疗记录由获准医师办理。

## 医师 · 接续病历和后续安排

从本人工作台进入「检查记录工作台」。按同一就诊编号打开「待确认草稿」续写，或打开「查看当前确认版」查阅已生效内容。输入草稿后保存；完成核对并确认后再检查版本号。通过历史版核对更正前记录。按当前授权安排后续诊疗；前台可核对安排，患者可从已发布报告或原就诊查看其获准获取的结果。

## 离店及其他岗位

| 岗位 | 核对事项 |
| --- | --- |
| 护理与药房 | 门店开通对应职责后，核对本次就诊、执行或调配记录和经办人。临床启用条件见报告。 |
| 财务与主管 | 按结算单核对应收、线下实收、退款和复核人。申请尚待复核时应保留其待办状态。 |
| 患者 | 回到原就诊查看已发布报告和结算单。复诊建议、可选时段与已确认的预约分别显示。 |

公开资料只列入口与核对方法。验收用账户、业务编号及可写范围随邀请交付。门店现场启用项目以本机构开通记录为准。
