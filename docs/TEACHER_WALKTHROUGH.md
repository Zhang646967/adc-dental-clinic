# 试用指南 · 从门店到病历

可以先以访客身份浏览，再用分配的合成账号体验岗位。下列操作可以停在查看或核对这一步。多人演示时，记下同一笔就诊的门店、时间和编号，便于下一个岗位接着看。

## 访客 · 找到能办理这项服务的门店

1. 打开[门诊首页](https://lijiahao.duckdns.org/)，在「查找门店」中选择城市。
2. 打开一家门店的「本店服务」，选择一个服务。核对门店、服务内容和费用说明。
3. 返回目录，再选一家门店。各门店的服务和可约情况按本店实际展示。

## 患者 · 看我的预约与就诊结果

1. 在[患者登录](https://lijiahao.duckdns.org/portal/login/)中使用分配的患者账号。若私有邀请已填好账号，直接点登录。
2. 打开我的预约，核对就诊人、门店、医师和时间。可以打开仍可改期的预约，选新时段，先在核对页比较两次安排。
3. 从历史就诊打开一笔已结算的记录，核对本次金额和收退款；有已发布检查报告的记录可以继续打开准确版本。记录内容随试用样本而异。

## 前台 · 找到正确的患者

1. 从[员工登录](https://lijiahao.duckdns.org/accounts/login/)进入前台工作台。若页面要求选店，选择试用邀请指定的门店。
2. 打开患者档案，输入邀请中的姓名或完整患者编号。遇到同名时，按患者提供的编号逐位核对后打开档案。
3. 从预约与到诊清单打开该患者的预约，核对门店、时间和状态。只想参观时，在详情页即可完成核对。

## 医师 · 接续本次就诊

1. 使用医师账号从[员工登录](https://lijiahao.duckdns.org/accounts/login/)进入本人工作台。
2. 进入检查记录工作台，用「待确认草稿」或「已有确认版本」查找负责的就诊。打开前先核对患者编号和就诊时间。
3. 打开对应检查记录，查看当前确认版本。需要查看初诊或复诊完整文书时，进入「病历文书与待办」。草稿、历史更正和已确认文书各有自己的状态。

如果登录后看到其他岗位，先核对账号和当前工作区。若清单为空，核对指定门店、日期和样本；公开目录仍可直接浏览。
