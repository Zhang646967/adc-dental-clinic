## 检查重点
暂停后各创建入口都拒绝新增；既有有效邀约按精确患者/时段/期限核验后接受；不提供HTTP布尔开关绕过暂停。
签名预览和草案包含接收修订号，暂停→恢复仍拒绝旧预览。成功请求重放只返回既有结果，不撤销其后合法变化。
源出诊行锁仍是预约、邀约发布、接受与接收控制的共同协议；暂停不改变is_active，原重叠约束仍占住牙医出诊时间。
替代时段继承暂停标志，避免停用/替换时隐式恢复接收。普通前台/患者无新接收控制权限。

数据库和HTTP断言目前是**待执行预期**。应用服务协议不限制数据库owner任意SQL，也不能保护旧版本代码与新版本同时写入。
