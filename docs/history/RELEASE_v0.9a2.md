# 当前候选：0.9.0-alpha.2

以ADC中期报告R4.0为对应分析基线。用户运行环境v0.7不由本包修改。

## 使用顺序
1. 先保存本地v0.7源码和数据库备份，不要删除volume，不要发送.env或密码。
2. 最先在独立解压目录运行`docker compose -p adc-v09-verify -f compose.verify.yaml run --rm verify`。该配置不读取旧卷，不带原.env值，测试使用临时合成数据库。结果写入本目录evidence/verification。
3. 隔离验证成功后，累计更新包可以覆盖原v0.7源码（保留.env、历史数据卷），通过`UPGRADE_V09_WINDOWS.cmd`运行备份、校验、迁移与完整测试。此Windows脚本本轮没有实机执行。
4. 任何错误停止并保全日志。备份存在或pg_restore --list可读不等于恢复演练；升级后如有新写入，不能盲目恢复旧快照而丢数据。
5. production相关文件只是候选。详见deployment/README.md；不能把开发端口直接公开，也不能仅改变环境标志就宣称发布。

完整源码与累计包无需先安装v0.8-alpha.2或v0.9-alpha.1。源文件校验是完整性检查，不是数字签名或软件安全认证。

## 演示新增功能
- 同一患者/前台身份：只读模式允许核对本人/本店候补结果，不允许接受或取消等写业务。
- 技术管理：有未完成预约的普通账号可进入“紧急安全封禁”；再次验证密码和确认后，原密码失效，业务历史仍在。
- 恢复：先重置密码，账号仍停用；再明确启用。旧会话不能复活。
