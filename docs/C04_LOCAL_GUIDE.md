# 本地患者找店使用说明

浏览门店 → 选服务 → 患者登录 → 选就诊人 → 核对资源 → 明确确认。

网站打开 http://127.0.0.1:18000/ ，无需登录即可浏览。门店页可手动选城市、区域搜索，或主动定位后由近到远排序。门店均为课程虚构资料，电话和导航操作不会真实发起。

长沙四家已配置服务、椅位和未来出诊；其余十六家仅展示资料。营业不等于有号，候选查询不占位。选择服务后才登录患者通道，员工从独立的“员工登录”进入。原账号密码不变，在本机 `.rc/private/demo-credentials.txt` 私下查阅；新增合成医师初始密码在 `.course-private/c04-20261024/assigned-accounts-private.json`，不要上传或转发。

前台按原日周排班办理出诊及调班；主管进入本店“门店公开资料”预览并发布。资料更新会使旧的新预约预览失效，已确认预约保留当时联系信息；搬迁仍须人工协调原约。

小程序本地包位于本机项目 `.course-private/c04-20261024/wechat-local`，后端为同一本机系统，使用游客AppID并关闭本地域名校验。已有17页及官方离线语法检查、实际后端Page处理器验证；尚无注册AppID，未声明微信工具运行、真机或体验版上传通过。账号和手机号本地替身流程已交付，见[C1-WX试用](C1WX_LOCAL_GUIDE.md)；真实微信仍需平台条件。

门店配置、患者授权、预约、治疗与资金是不同事实。本批找店和配置不会生成治疗或收款。正式课程报告从仓库根目录“课程报告”直接查阅，Word／PDF固定名称已更新。

思维导图：公开找店 → 服务意向 → 分流登录 → 合法就诊人 → 统一资源预约 → 前台排班及原承诺。
