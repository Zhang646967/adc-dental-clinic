# B1.1 预约取消分析与服务改进

时段线索 → 原因核实 → 联系责任 → 具体措施 → 后续窗口复核。

本功能解决“取消集中在哪些安排、为什么、谁继续办理、是否有可核对的后续结果”。演示只使用合成数据，不把演示比例当作真实经营发现。

## 日常使用

1. 主管从工作台打开“取消时段分析”，选择预约开始日期、星期及开始时段。总部先选诊所，跨店履约汇总仍走原运营总览。
2. 每格显示患者取消的分子／分母；诊所取消、爽约、到期未核实、未来预约和改期前身分开。少样本仍可查阅，不能据此生成高风险排行。
3. 前台打开“取消原因跟进”，核实原取消说明，记录分类、联系结果、责任人和下次联系期限。原说明不覆盖。已另约须核对同店同患者的真实有效预约编号，系统不会代为建约。
4. 主管按一个诊所、星期和时段建立改进措施，指定执行人、期限、具体行为及完成标准。原窗口的计数和查询时点一并保留。
5. 负责人开始并提交实际执行；不同账号的主管复核后续窗口及依据。可以如实标为样本不足或不可比。待复核时负责人失效，主管可重新分配或终止，保留历史。

## 口径

沿用原成熟预约定义：按Asia/Shanghai的预约开始日期归期，结束时间已到才纳入结果。到诊A包括已到诊、有治疗结束和无治疗关闭；P为患者取消、C为诊所取消、N为核实爽约、U为到期未核实。改期前身R单列，后继按自己的时间和结果计算。

患者取消率=P/(A+P+N)，爽约率=N/(A+P+N)，整体取消率=(P+C)/(A+P+C+N)，完整率=(A+P+C+N)/(A+P+C+N+U)。零分母显示无法计算；查询不修改业务。分组为08–10、10–12、12–14、14–16、16–18、18–20及其他，左闭右开、跨午夜按开始归组。

排行仅限同店每格主要分母≥30、完整率≥95%的调查线索。这是课程展示规则，不是统计显著性、临床质量或员工绩效判定。服务类型、节假日及预约提前天数可能不同，现阶段不能自动认定因果或改善。

原始取消文字保留；分类只能由本店前台核实，可追加更正，未提供保持明确缺失。取消提前量只取与该Visit关联的明确取消审计事件时间；没有事件就显示未知，不能用创建时间代替。开始后取消另列。

措施原窗口及后续窗口保存不可变快照。确认时重新核对当前数据；窗口未完整结束、早于本次执行开始、相互重叠、授权撤销或过期页面不能被当作有效复核。样本或完整性不足不能保存为“已核对变化”的正常比较。数字变化不自动证明措施有效。

## 职责与权限

| 身份 | 可办理范围 |
|---|---|
| 前台 | 本店取消个案、分类、联系责任和结果；本人负责的改进措施执行 |
| 主管 | 当前诊所聚合分析、措施安排、责任调整与独立复核；不取得患者姓名、电话、原取消文字或病历 |
| 总部 | 获授权诊所的聚合分析；不查看联系个案、措施自由文字或执行写入 |
| 其他四类身份 | 沿用原职责，不因本功能取得新的患者或运营写入权限 |

跟进记录不会重开已取消Visit，不自动通知患者、发起候补邀约、调整排班或改变账务。联系、另约、候补及出诊协调使用既有业务操作。措施办理历史只追加；同一确认重复提交返回原结果，并发复核仅保留一个合法结果。

## 模型与设计

新增operations领域拥有CancellationFollowUp、AppointmentImprovement和AppointmentActionEvent；调度领域继续拥有Visit及其原状态变化，临床与财务继续拥有版本和资金。仅增加一份迁移，原30份文件不修改。

- [接诊领域关系](diagrams/domain_care.svg)：患者、医师、诊所分开；出诊覆盖、就诊版本、实际治疗、逻辑结算及更正分别建模。
- [服务改进领域关系](diagrams/domain_appointment.svg)：原取消、跟进、另约及措施分别关联；每条办理历史恰属于跟进或措施之一。
- [预约状态](diagrams/visit_state.svg)：改期旧对象进入终态并新建唯一后继；原约失败保护、患者自助取消限制及财务更正在原服务内执行。
- [措施状态](diagrams/improvement_state.svg)：开始、提交、退回、重新分配、独立复核及终止均有明确操作者和依据。

这些是代表性领域关联及对象状态视图，不是全部物理字段或业务流程图。角色与诊所权限仍以工作上下文和实际服务校验为准。科室、房间、椅位日历及小程序尚待后续实施。

## 验证

[执行证据](evidence_b11/README.md)区分完整回归、浏览器、独立事实核算、备份恢复和本机更新。新增44项PostgreSQL验收覆盖固定算例、时段边界、跨日、零分母、缺失、跨店、撤权、旧页、重复提交、独立及并发复核。既有容量结果仍按原日期读取，不借用为本轮新负载结果。

思维导图：分析 → 数量与缺失 → 分类与联系 → 原窗口／责任／期限 → 执行提交 → 独立复核与保留历史。
