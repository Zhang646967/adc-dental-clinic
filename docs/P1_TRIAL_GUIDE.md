# P1 选诊与经营试用

公开找店选医 → 登录选择就诊人 → 资源确认成约 → 履约与月度经营。

匿名从首页门店卡片或 `/dentists/` 进入，按城市、区域、服务和线上预约条件筛选；定位由使用者主动授权后按近到远排序。门店详情介绍团队、实际服务及接诊日期，医师详情可切换常驻与轮诊门店。请选择该店实际发布的出诊日；轮诊医师并非每天都在同一门店。

患者登录后进入原就诊人及代理授权流程；登录前选择只是意向，正式预约再次核对患者、服务、出诊与资源。没有合适时间时可明确选择其他医师、同城门店或候补。改期和候补继续使用原确认流程。

员工使用独立 `/accounts/login/`。医师在 `/profiles/` 进入本人介绍并提交，本店主管在同一入口审核采用具体版本；撤回介绍只停止展示，结束任职则保留原承诺并交给前台协调。**排班仍由前台负责**，日周排班入口沿用原工作台。

月度经营入口 `/operations/management/`，全链汇总 `/operations/management/chain/`。主管提交本店成本，另一个财务账号复核；总部费用保留总部中心。公共成本按发布工时分摊，来源与分币尾差可核对。未完整核算时不出具正式利润；月报确认与修订保留版本。成本登记不等于付款。

八城二十家门店均准备了至少三名医师、四项差异化服务、两把椅位及必要设备、未来十四天出诊。它们全部为课程合成配置；角色账号和密码在本机下载目录“ADC系统试用/P1账号与入口.txt”，不存放在公开仓库。

小程序在同目录“微信小程序”，支持门店详情、医师列表及详情，复用上述账号、就诊人与预约数据。导入包含 `project.config.json` 的完整文件夹，保留原AppID和私有工具设置；23页开发联调包指向独立合成教师HTTPS。真实微信、真机与短信条件另见[WX1指南](WX1_GUIDE.md)。[业务口径](P1_PROFILE_MANAGEMENT.md) · [已执行验收](evidence_p1/README.md)。
