# UX2 预约接诊与财务表单

当前范围 → 快捷清单 → 分组录入 → 错误定位 → 原预览和独立审核。

预约清单增加就诊编号、快捷待办和可移除条件；接诊按复核、草稿、实际治疗、完成核对组织；财务区分资金事实、渠道凭据和依据。保持原角色、诊所、分页、版本、签名和明确确认。

检查覆盖输入保留与错误焦点、原生标签、键盘Enter/Tab、320/390像素及200%文字、无脚本、主管身份隐藏，以及完整接诊发布和财务合法/非法流程。财务五诊所另有568项浏览器检查和20项独立资金核对。首次完整回归发现已关闭接诊的历史复核提示被缩写，已恢复并全量复跑。
