# 领域和状态模型

本目录保留业务领域、状态及既有流程图。主要领域视图为诊疗结算、电话接待及资源占用；状态图分别解释就诊、接待和资源协调。DOT源文件和SVG／PNG同目录，当前八幅模型由`docs/report-source/render_models.cjs`导出。

数据库表、主外键、可空和连接表请看独立的[当前数据库ER](../database/README.md)。领域图不代替数据库ER；资源来源的概念组合也不是新增数据库表。课程报告第4.13节加入四幅真实ER，并保留原领域与状态模型。

management_preview为带水印的静态合成夹具节选。模型图是本项目分析设计表达，不是UML标准工具认证。
