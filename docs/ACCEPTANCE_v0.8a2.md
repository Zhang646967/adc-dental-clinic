# 目录增量待执行验收

以下是计划，不是本环境实测结果。使用合成数据。

1. 财务登录可看到“治疗价格目录”；总部有只读列表、无新建/调价入口；患者、牙医、主管和技术角色直接URL及POST均拒绝。
2. 财务新建唯一编码、非负至两位小数单价、有单位及依据的目录；重复编码拒绝，不覆盖原项目。
3. 核对旧单价后修改当前价格；旧页面价格或授权变更后拒绝，未勾确认不提交；同价不制造无意义更改。
4. 先用旧价完成一张合成账单，再调价；旧治疗行、旧单据总额保持原值；新治疗录入使用新的当前价。
5. 注入审计失败，价格写入回滚；在两条真实数据库连接上检验竞争（本次已写的16项并未穷尽并发矩阵）。
6. 再运行全部既有预约、候补、身份、接诊、财务和引导回归；保持原界面规则。

账单更正仍使用既有独立更正流程，不通过目录调价修改历史。无删除功能；停用与改名待后续规则。
