# P1 需求与验收追踪

| 业务问题／用例 | 规则与模块 | 执行入口 |
|---|---|---|
| 本人介绍与各店采用 SU-102/103 | 版本、独立审核、原发布保持；registry/profile_services.py | ProfileTests的提交、退回、撤回、自审、撤权、跨店、旧预览与重复提交；真实Chrome审核表单 |
| 常驻轮诊及退出 SU-104 | 任职非专业授权，退出保留原约；统一排班／资源锁 | 多店身份、任职有效期、原出诊启用、结束与成约并发；五店／二十店课程配置核对 |
| 门店资料与图片 SU-105 | 数据库规范化图片、公开投影白名单 | 图片归属、未发布隐藏、历史与不可变守卫；恢复逐表及二进制字节比较 |
| 两条选诊路径 SU-106/107 | 批量公开投影、服务适配与近期出诊 | 网站／小程序投影一致、匿名不写业务、二十店公开读取、轮诊详情 |
| 登录与患者切换 SU-108 | 选择为意向，原账号／就诊人／资源合同重核 | 普通密码登录保留医师；实际预约、重复确认、改期；既有代约／候补回归；12个P1原生处理器场景 |
| 成本归集 SU-109 | 来源、期间及同店归属；登记不付款 | 成本无资金副作用、采购区分、来源重复、跨月维修来源并发 |
| 独立复核 SU-110 | 不可自审、完整／零费用、权限撤销 | 多角色自审拒绝、待审阻断、缺失与零值、新成本失效、撤权、只读 |
| 经营月报 SU-111 | 完成期产值、业务日回款、工时分摊 | 跨月收退款、多版本账单、零收入成本、零工时、分币守恒、暂停仍计工时、医生本人投影 |
| 费用与月报修订 SU-112 | 追加引用、来源变化与快照 | 设备费用更正、旧报告保持、并发重复成本确认、旧预览失效、数据库不可变守卫 |
| 七岗位与窄屏 | 当前岗位、当前店、公开／内部边界 | PostgreSQL拒绝路径；真实Chrome七角色、390px、200%文字、键盘；原生官方23页离线编译 |
| 有界容量 | 20账号、30分钟、平均5rps、80:20 | 原五店临床基准与二十店画像／经营读取+真实草稿写入分开记录；独立DB oracle验证副作用 |
| 恢复与安装 | 原数据密码、配置、DB卷及RC标签保持 | 原加密备份恢复后追加迁移；含新图片版本成本与月报的加密独立恢复；准确CI后保护更新 |

测试函数在 `tests/test_profiles_management.py`，原规则回归持续覆盖既有业务。浏览器、容量和恢复不是用例文字的替代品；准确提交、运行结果和未完成条件见本目录执行记录。
