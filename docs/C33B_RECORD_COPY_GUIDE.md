# 病历副本申请与领取

申请范围 → 身份与用途 → 独立医务审核 → 固定电子副本 → 原账号确认领取。

患者网站从“我的账号 → 病历副本申请与领取”进入`/portal/record-copies/`；小程序从“我的”或“就诊”进入“病历副本申请与领取”。员工从独立工作台进入`/clinical/record-copies/`。

## 申请及范围

本人选择同一门店一至十次已结束接诊、需要的资料类别及用途。四类资料为病历与检查、方案与实际治疗、告知问答与决定、选定版本医疗费用。默认选择各次接诊最近固定版本；需要历史版本时单独选择该次接诊和明确归档包。选定版本不因后来补正、收费目录或实时余额变化而重绘。

尚无固定材料可以提出申请，保留待核验事项，由前台联系负责医师完成归档；不会假报资料齐备或因欠费拒绝申请。本在线入口办理已结束接诊的固定电子材料；进行中的接诊、未入库资料和需要机构证明印记的交付请联系门店另行受理。

## 身份与独立审核

有本店专项材料受理职责的前台核对患者及领取人身份、实际账号、本用途、范围、原件内部编号和领取期限。监护或书面受托复制由前台另行登记，不能转换代约或医疗决定授权。专项职责默认关闭；技术管理员按机构决定登记，不因此取得医疗正文。

前台只看必要身份、用途、资料类别和办理状态。另一名具备本店专项职责及具体服务读取范围的医师核对实际拟交付内容；申请人、材料核验人及原负责医师不能独立批准。通过、退回和不通过均保存记录。身份变化时可退回材料重核；申请人补充说明后明确再提交，原用途与范围保持，需改范围时另提申请。

审核通过后，现有通知工作进程每轮最多处理一份副本。副本依据获准的归档快照投影生成，包含所选版本、资料类别及缺项说明，不直接开放员工归档包，也不附加身份材料核验信息或财务渠道凭据。生成失败保留原任务；原依据仍有效时前台明确重试，依据变化时停止旧领取并重新核验。

## 受控领取

本人或专项核验的指定账号查看自己的办理进度。没有本人病历关联的注册账号也可办理自己的专项副本，不能借此预约、读取完整病历或账单。

领取前再次预览患者、用途、资料和领取账号，明确确认后取得两分钟有效的领取入口。每次请求文件仍核对实际登录会话、原工作区、指定账号、有效期限、审核职责和准确文件；仅有链接无法读取。退出、换账号、撤销、到期或依据变化后拒绝新领取。

领取期限默认由前台填写未来七日，可在未来三十日内明确选择。这是ADC办理规则，不是病历保管期限。到期不删除申请或文件，重新申请后另行核验。已交付到个人设备的副本无法远程收回。

系统记录服务端已生成文件响应；这不证明患者已经阅读或网络完整接收。网络中断后从原申请重新领取，原包、历史和资金保持。电子副本明确提示机构证明印记和可靠电子签名未由该功能提供。
