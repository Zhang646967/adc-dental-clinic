# 本地医保结算与基金清算办理

实际费用 → 核对模拟待遇 → 明确分担 → 独立复核 → 患者收退款／基金核对 → 撤销接续。

本指南使用课程合成资料和本地模拟结果。按[交付证据](evidence_c61bc/README.md)核对当前是否已安装；真实医保联网条件尚未具备。

1. 本店前台从已发布账单进入医保结算，核对原收费行、有效目录适配和患者最新模拟待遇，填写本次明确分担及依据。预览保留原金额；未知或未通过结果不能当作付款。
2. 正常受理、处理中或回复丢失均保存原请求编号。后两种情况从原单查询，不重建申报。由另一财务账号复核最终分担；原现金收退款仍使用原申请及独立审核流程。
3. 财务从“基金资金”查看银行依据，先按R1导入合成CSV，再选择相应流水登记基金到账或退回。另一财务账号核对；同一流水不能同时用于患者现金对账。
4. 从已核对银行依据进入“分配”，选择同店申报和具体金额；可以部分分配或一笔流水覆盖多笔。先提交、后独立复核。查看“基金申报”核对每笔应收、净到账、待审和未核销余额。
5. 尚未到账、短付、扣减或未知时建立差异事项，指定财务负责人和下次期限。沟通、换人、结束均追加记录；结束不会自动抹平账款。
6. 原结算需要撤销时，由本店前台或财务在原单发起；回复未知继续查询原撤销编号。已到账基金先办理有流水依据的退回及分配；另一财务账号核对后终结。原已收现金保留，患者退款仍独立办理。

日结分别展示原四项现金总额、渠道对账和基金清算。原接诊业务日的基金应收与银行记账日到账分列，次日到账不改原收入。患者和代约人不获得财务管理权限，主管及总部不读取患者结算明细。

完整路径及负例见[业务合同](C61BC_SETTLEMENT_CONTRACT.md)。原私有账号说明继续在本机私有目录；不要把密码、真实患者资料或银行流水上传仓库。
