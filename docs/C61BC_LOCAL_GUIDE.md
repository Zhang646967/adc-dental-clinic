# 本地医保结算与基金清算办理

实际费用 → 核对模拟待遇 → 明确分担 → 独立复核 → 患者收退款／基金核对 → 撤销接续。

本指南使用课程合成资料和本地模拟结果。按[交付证据](evidence_c61bc/README.md)核对当前是否已安装；真实医保联网条件尚未具备。

1. 本店前台从已发布账单进入医保结算，核对原收费行、有效目录适配和患者最新模拟待遇，填写本次明确分担及依据。预览保留原金额；未知或未通过结果不能当作付款。
2. 正常受理、处理中或回复丢失均保存原请求编号。后两种情况从原单查询，不重建申报。由另一财务账号复核最终分担；原现金收退款仍使用原申请及独立审核流程。
3. 财务从“基金资金”查看银行依据，先按R1导入合成CSV，再选择相应流水登记基金到账或退回。另一财务账号核对；同一流水不能同时用于患者现金对账。
4. 从已核对银行依据进入“分配”，选择同店申报和具体金额；可以部分分配或一笔流水覆盖多笔。先提交、后独立复核。查看“基金申报”核对每笔应收、净到账、待审和未核销余额。
5. 尚未到账、短付、扣减或未知时建立差异事项，指定财务负责人和下次期限。沟通、换人、结束均追加记录；结束不会自动抹平账款。
6. 原结算需要撤销时，由本店前台或财务在原单发起；回复未知继续查询原撤销编号。已到账基金先办理有流水依据的退回及分配；另一财务账号核对后终结。原已收现金保留，患者退款仍独立办理。

日结分别展示原四项现金总额、渠道对账和基金清算。原接诊业务日的基金应收与银行记账日到账分列，次日到账不改原收入。患者和代约人不获得财务管理权限，主管及总部不读取患者结算明细。

完整路径及负例见[业务合同](C61BC_SETTLEMENT_CONTRACT.md)。原私有账号说明继续在本机私有目录；不要把密码、真实患者资料或银行流水上传仓库。

## 从空资金账开始的一条课堂办理路线

使用现有课程门店与私有岗位账号，按前台、医师、两名财务的职责办理。患者和代约人继续使用患者通道；员工使用网站。当前原系统尚无治疗、账单或资金记录，先通过正常业务形成实际收费，不能直接填一笔医保结果替代接诊。

| 步骤 | 经办岗位与操作 | 核对结果 |
|---|---|---|
| 1. 形成实际费用 | 前台预约、到诊；已获相应门店及动作授权的医师核对健康资料、确认检查与实际治疗、发布账单 | 费用来自实际执行。下例假定账单100元；真实练习金额不同时，按实际收费逐行核对 |
| 2. 先自费 | 前台申请收100元，另一财务账号核对通过 | 原收入100、实际现金100；没有医保分担 |
| 3. 备齐模拟资料 | 主管核对本店已启用安排及收费映射；前台保存患者有效模拟待遇。目录或单位不明确时先完成核对 | 保留已发布的原目录与审阅记录；不更改实际收费 |
| 4. 明确分担 | 前台预览现金责任30、个人账户20、基金50，明确确认；财务独立复核。可用“回复丢失”练习原编号查询 | 收入仍100；原已收100，患者待退70；回复未知时先查询，不能重建申报 |
| 5. 退还多收现金 | 前台申请退70，财务独立通过 | 净患者现金30、个人账户承担20、基金应收50；不能把基金记成再次收款 |
| 6. 分两次到账 | 主管在本店银行转账账户导入20和30两笔合成入账；财务分别登记用途，由另一财务核对，再分别分配到原申报并独立确认 | 只分配第一笔时基金待核销30；两笔通过后基金净到账50、待核销0 |
| 7. 跟进差额 | 第一次到账后创建短付或未到账事项，指定有效财务负责人和未来期限；第二笔核销后追加结束依据 | 联系与结束记录保留；事项结束本身不生成资金 |
| 8. 原单撤销 | 在原结算发起模拟撤销；未知则查询原编号。依据两笔银行退回分别分配20和30，再由另一财务账号核对撤销 | 只退20时不能终结；全部退回后可重新预览并确认。原治疗、收入100和现金30保留，患者待收恢复为70 |

步骤8撤销的是医保分担。已经完成的治疗和实际现金各有自己的事实与处理流程，不能由医保撤销顺带删除。

合成流水示例用于同一课程门店的银行转账账户。记账日按实际练习资料填写；以下日期仅为本次课程示例。同一交易编号重复上传会被识别，重新练习使用新的编号，不覆盖前一次记录。

```csv
transaction_id,booked_on,direction,amount,currency,reference
SIM-COURSE-IN-01,2026-10-25,IN,20.00,CNY,SIM-FUND-ARRIVAL-01
SIM-COURSE-IN-02,2026-10-25,IN,30.00,CNY,SIM-FUND-ARRIVAL-02
SIM-COURSE-OUT-01,2026-10-25,OUT,20.00,CNY,SIM-FUND-RETURN-01
SIM-COURSE-OUT-02,2026-10-25,OUT,30.00,CNY,SIM-FUND-RETURN-02
```

每次确认前核对门店、原账单、方向、金额、独立经办人及最新进度；浏览和候选不等于确认。目录映射必须确实支持所填基金金额，不能仅为凑齐示例等式选择不相容的项目。

思维导图：正常接诊 → 原收费 → 自费收款 → 明确模拟分担 → 多收退款 → {部分到账、差额责任、补足核销} → 原单撤销及基金退回 → 原治疗与现金历史保留。
