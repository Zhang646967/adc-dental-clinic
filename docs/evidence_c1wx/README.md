# C1-WX 本地患者账号与本人核验

私有本地凭证 → 患者渠道账号 → 联络来源 → 本人申请 → 独立前台决定 → 明确激活 → 原预约服务。

当前为已验证源码候选，尚未安装到原系统。完整回归通过1,104项源码规则和1,765项PostgreSQL业务、HTTP与并发用例；原生客户端207项结构与传输检查、19页官方离线WXML及WXSS检查通过。另有实际Page处理器连接隔离后端的34项检查，网站完整旅程18项检查。它们不等于微信运行时或真实微信身份验证。

本轮修复390px大字模式的长账号溢出，并补齐本人关联暂停后的原行复核恢复。旧的“暂停即不能认证”测试改为验证“能认证本人账号、不能激活患者或读取业务”，保留安全停用账号限制。全量回归先前的单项预期冲突和测试桥配置错误保留在私有原始记录，后续通过不会改写失败历史。
