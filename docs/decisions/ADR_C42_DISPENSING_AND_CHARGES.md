# C4.2 调配、实际发退药与费用版本

通过审方 → 确认本店价格 → 记录实际发药或停止余量 → 发布接诊账单 → 退药后独立更正与退款。

## 办理职责

- 合成实例启用 C4.1 和 C4.2 后，具备本店有效调配职责的药师可操作。发药人与开方人分离。审方和调配分别授权。
- 药师确认当前通过版本、精确条目和本店 CNY 单价。演练发药窗口为独立审方通过后 24 小时，办理时重检诊疗和专业依据。已保存划价随版本保留。
- 每次只确认实际发出的数量。累计发出不能超过审定数量，退药引用原发药记录。停止余量后保留已发药事实并允许退药。待审、尚有未处理余量的处方先完成处置，再关闭接诊。
- 仅发药采用独立接诊结果。治疗与药费分别存明细，原无治疗零金额路径保留。发药和退药均不直接修改账单或生成资金。
- 接诊关闭后的实际退药，由负责医师发起费用更正并由财务独立复核。新版本保存准确发退药记录截止点。原账单、原收款和治疗明细保留，退款继续从原有独立记账流程办理。
- 本人网页与小程序读取同一张已发布账单。药费只提供名称、计费单位、发退药净数量、单价和小计。已有代理权限继续按原业务范围。

## 一致性与实施边界

- 事务内按账号、角色、出诊、就诊、处方顺序重检。预览绑定岗位与诊所，重复确认使用原操作回执。报价、发退药、停止和已发布明细均保留历史。
- PostgreSQL 检查处方与划价来源、发出和退回上限、药费净量、费额及发布版本。空库可回退，已存在药事或费用历史时拒绝回退。
- 临床、财务及患者界面读取各自业务范围。日志仅留动作和编号。新增演练单价与工作职责通过合成配置命令登记。
- `ADC_PRESCRIPTION_REHEARSAL=1` 与 `ADC_DISPENSING_REHEARSAL=1` 只在明确标记的合成实例使用。含演练药费的账单走自费。批次追溯、护理实际执行进入 C5，药房平台、真实药品和岗位资格在合作机构验收。
