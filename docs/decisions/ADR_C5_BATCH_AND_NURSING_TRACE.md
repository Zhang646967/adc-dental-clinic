# C5 库存批次、护理执行与召回追溯

到货 → 批次可用性核对 → 实际发药或耗用 → 按来源追溯 → 异常交接。

## 库存与药事

- 每店按条目、批号、效期和到货凭据入库。药房调配职责管理药品批次，门店主管管理耗材及植入材料批次。
- 发药按一次实际出库选择一个批次，分次发药可记录不同批次。发药事实与库存流水在同一事务确认。过期、召回及数量不足均在确认时重检。
- 退药沿原发药批次登记隔离，不增加可发库存。旧发药历史中未知的批次保持未知。报损及到货、报损冲回保存原凭据和追加流水。
- 召回后停止新出库与给药。追溯按原发药或耗用记录列出就诊和患者编号，由本店授权岗位交接跟进。召回不会抹去既有业务或自动退款。

## 护理与无菌包

- 本店护理执行和无菌放行分别登记有期职责。默认不开通，工作区、职责和对象范围一并核验。
- 实际耗用、实际给药、无菌包使用及异常上报保存发生时间与责任人。给药关联发药和批次，已执行的数量不能再次退回。耗用和无菌包使用关联本次有效的实际治疗。
- 同一放行包最多登记一次实际使用。过期或已停用的包不能新用。停用保存原放行和使用记录。
- 医师从本次接诊查看护理交接，临床归档保存准确执行与批号。既有收费事实和患者代理范围保持独立。

## 一致性与交付范围

- 出诊、就诊、原来源、批次或无菌包按操作边界加锁。数据库核对跨店、物理来源、发药与给药／退药数量、库存非负及历史不可覆盖。
- 启用合成实例的 `ADC_STOCK_REHEARSAL=1` 后才提供上述入口。课程合成材料通过有审计的登记命令配置。试点药品、感染控制和实际供应商接口由合作机构另行验证。
