# C3.3A：准确来源、独立审核与固定包

状态：已实施，发布证据另见`docs/evidence_c33a/`。

业务问题：文书确认、接诊结束和收费发布均不能证明已有独立核对、固定版本及可追溯更正。归档后覆盖原记录会破坏责任和来源。

采用：保留模块化单体和原75份迁移，追加归档责任、申请、固定包、补正及事件五类数据与默认关闭的审核职责。临床模块仍拥有文书和检查，财务拥有原金额；归档只保存准确来源、独立审核及固定文件。

固定PDF使用本地ReportLab及附带开放许可中文字体，从获准快照生成。现有工作进程每轮有界处理，不建立新的队列服务。耗时渲染在事务外，发布在锁内重核来源、职责和原包，再原子保存文件与回执。失败保留任务并明确重试，禁止把生成中状态误当作已归档。

旧完整归档后的检查和文书追加分别引用获准准确草稿；应用确认与PostgreSQL延迟约束共同核对实际结果。未完成手续只保全现有资料，不把历史缺口改成事前通过。原财务更正、患者真实撤回及新就诊保留各自模块合同，旧包不重绘。

边界：软件所选的独立医师委任不冒充真实机构已经通过的医务制度。患者受控复制、证件附件库、机构印章、可靠电子签名、司法封存与自动销毁均不在本批新增范围。
