# 门店检查项目开通范围

报告、提醒和复诊已经共享就诊与报告版本。按整个实例开启这一能力，会让以前仅供演练的项目混入同一工作清单。现在将运行范围保存在检查项目上，由同一张项目表核对临床清单、患者投影和业务确认。

迁移 clinical.0024 只增加 operating_mode 字段与取值约束。原有行默认 REHEARSAL。新建门店项目须经可写配置、指定门店服务和技术岗位核验，执行与审核账号须不同，且分别持当前范围内有效的专业授权。正式运行的授权计算排除演练来源。使用本机构可识别的项目代码，重名的演练项目不能原地开通。开通不会创建专业资质或审核委任。

项目处于 SITE 时，报告由负责医师发布，经办职责逐次重验。暂停转为 SUSPENDED，撤销该项目的在用职责，保留已成立预约、原文、事件、提醒与预约关联。恢复要重新提交执行及审核人员。目录停售仅限制新申请，和项目暂停分别处理。患者报告由本人及具体版本限定；前台只查办理状态和复诊预约。迁移反向执行前检查是否已有门店项目，避免丢失开通边界。

每次实际暂停或恢复都会递增项目的运行版本。医师的签发提案和患者的复诊提案绑定该版本，即使项目在提案有效期内恢复，旧提案也不能成为新的业务记录。已经成功的预约仍可按原回执核对。
