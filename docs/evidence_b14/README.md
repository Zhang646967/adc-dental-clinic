没有意外HTTP失败、重复效果、观察到的OOM、意外重启或死锁增长。20个患者会话按20请求／4秒批次提供约5请求／秒。请求时延包括排队；预览和确认分别计入POST，不能把1800次POST称为1800次业务改期。148次资源采样和50次六项健康观察分别保留；[资源上限及实测峰值](resources.json)、[需求至测试](traceability.md)。

本次患者负载与历史混合岗位负载分开，不声称两者完全相同。测量镜像标签保留上一提交作为构建基线，运行内容为B1.4工作树；[502个运行文件逐字节比对](capacity_equivalence.json)说明实际代码，最终准确提交及浏览器另行记录，不将基线提交误称为已包含B1.4，也不声称又做过第二次三十分钟完整二进制负载。

产品修复包括原椅位自身占用误排除候选；取消跟进增加合法直接后继查询，保留原另约依据。验证脚本曾使用手工拼接的时间字符串、隐藏式日期控件及错误类名／字段名，后改为实际页面候选和可见控件；20秒预检因只完成预览、不含确认而明确未通过，改为完整40秒周期通过。私有原失败记录保留，脚本调整不归作产品修复，也不计入最终负载的零失败范围。

恢复采用同版本迁移先建库再恢复数据，核对全部行、结构及触发器；既有自动恢复工具对等价SQL表达比较的限制仍保留。上述结果仅证明受限容器下的合成课程场景，不证明独立公网、真实24小时连续运行、二十店商业容量或真实取消改善。服务器尚未购买，历史Windows原数据恢复未解决。
